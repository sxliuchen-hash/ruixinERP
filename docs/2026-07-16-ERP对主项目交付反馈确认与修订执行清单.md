# ERP 对主项目统一权限与 SSO 交付反馈确认及修订执行清单

## 1. ERP 正式确认

ERP 团队已审阅主项目 2026-07-16 正式反馈，并接受以下修订：

1. 主项目生产目标不再固定为 `release/20260715.2`，等待主项目完成隔离 MySQL + Redis 全量门禁后回传新的正式 Commit/Tag；
2. ERP 正式部署前必须提供不可变正式 Tag；
3. 本次不准备独立恢复主机，不在共享生产服务器安装 Docker；同一备份工件恢复 smoke 经项目负责人接受风险后改为建议项；
4. 取消恢复 smoke 不等于取消备份，必须执行停写、最终全量备份、压缩完整性检查、SHA-256 和异机副本；
5. 必须先部署 ERP 并同步 Manifest，再配置 `erp.app.view` 和开启主项目应用级 SSO；
6. ERP 修改 Nginx 后先执行 `nginx -t`，reload 后同时只读验证 `erp.iptt.top` 和 `iptt.top`；
7. ERP 线上 6 个未跟踪文件只允许原样备份和保留，本次不得清理、覆盖或提交；
8. 主项目服务器端只能由主项目团队执行生产变更，ERP 团队不得代执行。

正式 Tag 前的唯一允许顺序锁定为：

```text
主项目交付四套凭证、active kid、公钥
→ ERP 写入受控配置
→ ERP 真实生产预检 0 失败
→ ERP 创建生产正式 Tag
```

不得提前创建生产正式 Tag，不得使用缺少真实受控材料的预检结果，也不得绕过真实生产预检。

本文取代 ERP 原 2026-07-16 执行清单，作为当前双方部署准备、服务器执行和回传依据。

## 2. 项目负责人风险决策记录

### 2.1 本次接受的风险例外

本次 ERP 采用现有生产服务器直接部署：

- 不单独准备数据库恢复主机；
- 不在共享生产服务器安装 Docker；
- 不把真实恢复 smoke 作为本次部署硬门槛；
- 接受“备份可恢复性未经实际恢复证明”的剩余风险；
- 接受 MySQL DDL 可能自动提交、迁移中断后可能保留前序成功结构变化的风险。

本例外只取消恢复 smoke 硬门槛，不取消以下控制：

- ERP 停止外部写入和后台任务；
- ERP 数据库只读冲突检查；
- ERP 最终全量备份；
- 备份退出码、大小、SHA-256、压缩完整性和表结构抽查；
- 至少一份生产服务器之外的受控副本；
- 五项迁移逐项执行、逐项记录、失败立即停止；
- 不执行临时数据清洗和未经验证的逆向 SQL。

### 2.2 七天灰度

灰度 T0 不是代码部署时间，而是首个测试账号完成以下完整链路的时间：

```text
主项目登录 → ERP入口 → /sso/initiate → 主项目授权 → callback
→ Code兑换 → RS256验签 → ERP会话建立 → 权限和数据范围生效
```

T0 起观察七个完整自然日。

灰度期 ERP 配置：

```text
ENABLE_SSO_LOGIN=true
ENABLE_PASSWORD_LOGIN=true
ENABLE_LEGACY_SESSION=true
IP_AUTH_MODE=hybrid
```

T0+7、问题清零并由双方签字后，另行审批切换为：

```text
ENABLE_SSO_LOGIN=true
ENABLE_PASSWORD_LOGIN=false
ENABLE_LEGACY_SESSION=false
IP_AUTH_MODE=client_credentials
```

### 4.2 四套独立凭证

| Client ID | 方向 | 用途 | 主项目配置要求 |
| --- | --- | --- | --- |
| `erp-sso` | ERP → 主项目 | Code 兑换 | 主项目入站哈希 Client；仅 `sso.exchange` |
| `erp-main-api` | ERP → 主项目 | team scope、permissionVersion、专利业务 API | 主项目入站哈希 Client；仅五项最小权限 |
| `main-permission-center` | 主项目 → ERP | 拉取 Manifest | 主项目出站环境变量；不创建为入站哈希 Client |
| `main-provisioning` | 主项目 → ERP | Employee 幂等建档 | 主项目出站环境变量；不创建为入站哈希 Client |

`erp-main-api` 五项最小权限：

```text
team-scope.read
permission-version.read
ip.patent_query.execute
ip.patent_fee.read
ip.patent.read
```

后台任务白名单：

```text
metadata.allowedJobNames = ["patent-anomaly-scan"]
```

四套 ID/Secret 必须互不相同。主项目只在普通回执中提供 Client ID、授权、指纹和受控交付编号；Secret 通过密码库、受控文件或一次性安全渠道交付。
